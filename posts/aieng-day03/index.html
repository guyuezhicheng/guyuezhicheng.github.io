2. 学术雷达 · 第 3 期（2026-11-12 检索）

今天两条撞在同一个点上：「下一步走哪条分支、这轮循环还要不要继续」这个决定，到底由谁做。跟今天的课是正面相关，不是硬凑。

2.1 ProofCoder：把「写死的 tactic 生成循环」拆掉

  • 出处：arXiv:2611.14106《ProofCoder: Continuous Reasoning for Automated Software Verification》，v1 2026-11-10 13:59 UTC，cs.SE / cs.AI；机构 INESC-ID & IST, University of Lisbon（里斯本大学）、Politecnico di Torino（都灵理工）、Faculty of Engineering, University of Porto（波尔图大学）；https://arxiv.org/abs/2611.14106 。
  • 做了什么：用 Rocq 做形式化验证时，以往 LLM 方案被套在一个 rigid tactic-generation loop 里——外围系统管前提检索、证明状态、回溯，模型每轮只吐一条 tactic。ProofCoder 改成编码智能体式连续推理：拿证明助手的反馈自己决定「再去取信息 / 检查证明状态 / 改之前写过的片段 / 回溯到更早的位置」，在 tactic 级和整篇证明级都能迭代构造、修复、精化。AutoRocq Benchmark 的 280 道题上，最佳配置把证明成功率从 47% 提到 60%（相对 +27.7%），成本约减半。消融实验显示去掉连续推理后，回溯次数多 4–6 倍、更常丢弃自己的修订。
  • 改变了哪个旧假设：「证明搜索必须由外围系统用一个固定循环控制，模型只能在循环体内填一条指令」。这篇把控制流的主导权从框架挪给了模型，下一步做什么由运行时反馈决定，而不是循环结构预先写死。
  • 意义：控制流本身成了可以被推理、被改写的东西；在 Agent/程序合成方向，这是从「写循环」到「让循环自己决定怎么走」的一步。
  • 关联今天：这就是今天 while + if/else + break/continue 的放大版。你写的猜数字循环里「大了缩上界、小了抬下界、中了就 break」，正是「按反馈决定下一个分支」的最小可运行版本；2.1 里那个被拆掉的 fixed loop，就是 traps.c 里那个不带反馈、只会傻转的循环。
  • 状态：arXiv 预印本，未经同行评审、待复现；数字是作者在 AutoRocq 上的自测，暂无独立复现。

2.2 UniExit：continue-or-exit 不再靠静态阈值

  • 出处：arXiv:2611.09159《UniExit: A Unified Latency-Aware Early-Exit Runtime for Heterogeneous Edge AI》，v1 2026-11-06 08:40 UTC，cs.DC；机构 香港科技大学（广州）、山东大学、香港科技大学；https://arxiv.org/abs/2611.09159 。arXiv 页面 comments 标注「Accepted to ACM SenSys 2027」，论文首页列出的会议为 The International Conference on Embedded Artificial Intelligence and Sensing Systems, 2027, Boulder, CO, USA。
  • 做了什么：边缘设备上 CNN 感知和端侧 Transformer 混着跑，早退（early-exit）能省算力，但已有做法要么跟具体模型绑死，要么靠离线测出来的静态 latency profile，硬件状态一变就失效。UniExit 把 CNN block 和 Transformer layer 统一抽象成有序 stage，用一套通用 latency-aware 路由策略，根据运行时状态和推理进度预测「走到下一个出口要花多少」，做 budget-aware 的 continue-or-exit 决策；配了状态感知延迟预测、预测结果缓存复用、趋势兜底、CNN 出口稳定化。在多套边缘 / 边云平台上，单负载、并发异构、边云三种设置下都改善了 deadline 满足率和延迟-精度权衡，同时减少冗余出口计算与任务能耗。
  • 改变了哪个旧假设：「早退阈值可以离线量一次、写死在配置里，且每个模型各写一套」。它把「继续还是退出」变成每次循环都重新判断的运行时分支。
  • 意义：分支条件从常量变成状态的函数，控制流开始跟着机器实时状态走；对端侧推理（你后面 P5 会做）这是能直接用的思路。
  • 关联今天：字面意义上的「这轮循环还要不要继续」。flow.c 里 while (lo <= hi) 的每轮判断就是一次 continue-or-exit，if (mid == target) break; 就是一次提前退出。今天把 break/continue 的跳转位置搞清楚，后面看 early-exit、投机解码的接受/拒绝分支才不隔一层。
  • 状态：arXiv 上为会议接收稿的预印本版本（页面标注被 ACM SenSys 2027 接收），效果数字为作者自测、尚无独立复现；不把会议接收等同于结果已被验证。

甄别记录：检索中还出现 arXiv:2611.10913《Bit-level Perceptron Prediction for Indirect Branches》，标题最贴今天的「分支」，但 arXiv 页面 comments 明确写它是 ISCA 2019 会议论文的作者稿补档，不是本周新成果，未采用。

今日雷达一句话：分支和循环从来不只是语法，它是「谁来决定下一步」。今天先把决定权握在自己写的代码里，后面才谈得上交给运行时、交给模型。

3. 新知讲解

3.1 真值：if 判断的到底是什么

  1. C 没有 bool 原生语义（C99 的 _Bool/stdbool.h 是后加的）：0 为假，任何非 0 为真，包括负数、指针、浮点数。所以 if (-1) 成立，if (0.0) 不成立。
  2. = 是赋值、== 是判等。if (x = 3) 恒真且把 x 改成 3，是经典事故。常量写左边 if (3 == x) 能在写成 = 时直接编译报错（左边不可赋值）。
  3. 短路求值：&& 左边为假就不算右边，|| 左边为真就不算右边。if (a != 0 && 10 / a > 1) 靠这个才不会除零；反过来 if (p != NULL || *p == 'x') 是错的，得用 &&。
  4. 悬空 else：else 永远配最近的、还没配对的 if，跟缩进无关。traps.c 里那个 else 配的是内层 if，所以什么都不打印。写多行分支一律加花括号。

3.2 switch 与穿透

  1. switch 只能判整型（含 char、枚举），不能判字符串、浮点、区间；case 后必须是编译期常量。
  2. C 的 case 默认往下穿透，不写 break 就一直执行到下一个 break 或 }。多个 case 共用一段逻辑是有意利用穿透，其余情况一律补 break。
  3. default 放最后并加 break；漏了 default 时输入不在任何 case 就整段跳过，容易埋 bug。

3.3 三种循环与两个跳转

  1. while (cond)：先判后跑，可能一次都不执行。
  2. do { } while (cond);：先跑后判，至少执行一次，末尾分号别漏。
  3. for (init; cond; step) 等价于 init; while (cond) { body; step; }。三段都能省，for (;;) 是无限循环，靠 break 出。
  4. break：跳出最近一层循环或 switch，不是所有层。continue：跳过本轮剩余语句——在 for 里下一步执行 step，在 while 里下一步直接回到条件判断。所以 while 里 continue 前忘了改循环变量就死循环，traps.c 用 guard 把这个坑演给你看。
  5. goto 只在同一函数内跳，用来一次性跳出多层循环算合理，其余场景别用。

3.4 边界与防溢出（今天最该记住的两行）

  1. 二分中点写 mid = lo + (hi - lo) / 2，不要写 (lo + hi) / 2——后者在 lo + hi 超过 INT_MAX 时是有符号溢出 = UB（D2 讲过）。
  2. 试除判素数写 d <= n / d，不要写 d * d <= n——d*d 会先溢出，溢出后可能变成负数让循环停不下来或误判。
  3. is_prime 里 n < 2 直接返回 0，把 0、1、负数一次性挡掉；再单独处理 2 和偶数，之后只试奇数，循环次数减半。
  4. 循环不变式：while (lo <= hi) 每轮开头都保证「答案若存在必在 [lo, hi] 内」。能写出这句话，就说明终止条件和更新方向没搞反。
  5. 输入别用 scanf("%d") 后不检查返回值；用 strtoll + end 指针 + errno == ERANGE，把非法串、超大数、空串全挡在循环外。flow.c 里三个命令都是这套。

3.5 最小可运行示例：flow.c（三个程序合一个文件，命令行切换）

课表要三个程序，用 argv[1] 分派到 prime / table / guess，一份文件编译一次跑三遍，边界输入能批量喂。

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <string.h>

/* 返回 1 素数, 0 非素数; d <= n/d 防 d*d 溢出 */
static int is_prime(long long n) {
    if (n < 2) return 0;
    if (n == 2) return 1;
    if (n % 2 == 0) return 0;
    for (long long d = 3; d <= n / d; d += 2) {
        if (n % d == 0) return 0;
    }
    return 1;
}

static int cmd_prime(const char *s) {
    char *end = NULL;
    errno = 0;
    long long n = strtoll(s, &end, 10);
    if (end == s || *end != '\0' || errno == ERANGE) {
        printf("invalid input: %s\n", s);
        return 2;
    }
    printf("%lld: %s\n", n, is_prime(n) ? "prime" : "not prime");
    return 0;
}

static int cmd_table(const char *s) {
    int n = 9;
    if (s != NULL) {
        char *end = NULL;
        errno = 0;
        long long v = strtoll(s, &end, 10);
        if (end == s || *end != '\0' || errno == ERANGE || v < 1 || v > 9) {
            printf("table: n must be in 1..9\n");
            return 2;
        }
        n = (int)v;
    }
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            printf("%d*%d=%-3d", j, i, j * i);
        }
        putchar('\n');
    }
    return 0;
}

static int cmd_guess(const char *s) {
    char *end = NULL;
    errno = 0;
    long long target = strtoll(s, &end, 10);
    if (end == s || *end != '\0' || errno == ERANGE) {
        printf("invalid input: %s\n", s);
        return 2;
    }
    if (target < 1 || target > 100) {
        printf("target out of range 1..100: %lld\n", target);
        return 2;
    }
    int lo = 1;
    int hi = 100;
    int steps = 0;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        steps++;
        if (mid == target) {
            printf("target=%lld found in %d steps\n", target, steps);
            return 0;
        } else if (mid < target) {
            printf("step %d: %d too small\n", steps, mid);
            lo = mid + 1;
        } else {
            printf("step %d: %d too big\n", steps, mid);
            hi = mid - 1;
        }
    }
    printf("not found: invariant broken\n");
    return 1;
}

int main(int argc, char **argv) {
    if (argc < 2) {
        printf("usage: %s prime <n> | table [n] | guess <target>\n", argv[0]);
        return 2;
    }
    if (strcmp(argv[1], "prime") == 0) {
        if (argc < 3) { printf("prime needs an integer\n"); return 2; }
        return cmd_prime(argv[2]);
    }
    if (strcmp(argv[1], "table") == 0) {
        return cmd_table(argc > 2 ? argv[2] : NULL);
    }
    if (strcmp(argv[1], "guess") == 0) {
        if (argc < 3) { printf("guess needs a target\n"); return 2; }
        return cmd_guess(argv[2]);
    }
    printf("unknown mode: %s\n", argv[1]);
    return 2;
}

三个点自己对着看：cmd_guess 是 while + 三分支 + break 式提前返回；cmd_table 是双层 for 的 off-by-one（j <= i 不是 j <= 9）；cmd_prime 是 for 里的提前 return。猜数字这里用二分而不是随机数，是为了让输出可复现、能自动对拍。

3.6 跳转语义示例：traps.c

#include <stdio.h>

/* 故意不 break, 观察 case 穿透 */
static void switch_demo(void) {
    printf("== switch fall-through ==\n");
    for (int k = 1; k <= 3; k++) {
        printf("case %d -> ", k);
        switch (k) {
            case 1: printf("one ");
            case 2: printf("two ");
            case 3: printf("three ");
            default: printf("done");
        }
        putchar('\n');
    }
    printf("-- with break --\n");
    for (int k = 1; k <= 3; k++) {
        printf("case %d -> ", k);
        switch (k) {
            case 1: printf("one");   break;
            case 2: printf("two");   break;
            case 3: printf("three"); break;
            default: printf("done"); break;
        }
        putchar('\n');
    }
}

static void break_continue_demo(void) {
    printf("\n== break vs continue ==\n");
    for (int i = 1; i <= 6; i++) {
        if (i == 3) continue;
        if (i == 5) break;
        printf("%d ", i);
    }
    putchar('\n');
}

/* while 里 continue 跳过自增会卡死, 用 guard 兜住 */
static void continue_trap(void) {
    printf("\n== continue trap in while ==\n");
    int i = 0;
    int guard = 0;
    while (i < 5) {
        guard++;
        if (guard > 12) {
            printf(" guard fired: i stuck at %d\n", i);
            break;
        }
        if (i == 3) continue;
        printf("%d ", i);
        i++;
    }
    putchar('\n');
}

static void do_while_demo(void) {
    printf("\n== do-while runs at least once ==\n");
    int i = 0;
    do {
        printf("do-body with i=%d\n", i);
    } while (i > 0);
    printf("while(0) body: ");
    i = 0;
    while (i > 0) { printf("never "); i--; }
    printf("(none)\n");
}

static void short_circuit_demo(void) {
    printf("\n== short circuit ==\n");
    int a = 0;
    int b = 0;
    if (a != 0 && 10 / a > 1) b = 1;
    printf("a=%d b=%d, no div-by-zero\n", a, b);
    if (a == 0 || 10 / a > 1) b = 2;
    printf("b=%d\n", b);
}

static void dangling_else_demo(void) {
    printf("\n== dangling else ==\n");
    int x = 0;
    int y = 1;
    if (x)
        if (y) printf("A\n");
    else printf("B\n");
    printf("nothing above: else binds to inner if\n");
}

int main(void) {
    switch_demo();
    break_continue_demo();
    continue_trap();
    do_while_demo();
    short_circuit_demo();
    dangling_else_demo();
    return 0;
}

-Wall -Wextra 下 dangling_else_demo 会报缩进误导的警告，故意留着：把警告抄进笔记，它就是 3.1 第 4 条的实物证据。

素数 10 组期望输出（自己先手算再对）：

输入 0 1 2 3 4 9 97 100 -7 2147483647
结果 not not prime prime not not prime not not prime

2147483647 = 2^31-1 是素数，d <= n/d 在这里必须能正常终止，这是最大值边界的重点。

5 条全过才进 D4。任一不过，明天不学新内容，先把今天补到过；连续 2 天没过，回头补 W1。
