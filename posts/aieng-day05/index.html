2. 学术雷达 · 第 5 期（2026-11-14 检索）

今天两条都撞在「字节数组」上：一条把大模型压回单字节表示，一条在 C/C++ 里大规模找越界。都已逐条核对 arXiv 官方 abs / html 页。

2.1 One Byte, One Token：把 27B 大模型直接改成纯字节模型

  • 出处：arXiv:2611.13607《One Byte, One Token: Byteifying a 27B Hybrid-Attention LLM with Self-Generated Data》，v1 2026-11-10 05:33 UTC、v2 2026-11-12 11:34 UTC，cs.CL / cs.LG；作者 Liwei Zhang、ZhiMing Tong、Mochen Guan、Linzhe Li（通讯作者）；论文首页印出的署名单位为 Landi Lab / 澜砥实验室；https://arxiv.org/abs/2611.13607 。
  • 做了什么：把已训练好的 Qwen3.8-27B（48 层 Gated DeltaNet + 16 层全注意力）从 subword 模型直接转成纯字节级模型，词表从 248,320 砍到 384（256 个原本就在 BPE 词表里的字节符号 + 特殊 id），其余权重一个不动，也不用 patching 结构或局部编码器。用两阶段课程续训（先学字符↔字节编码，再学阅读），4.77 GB 监督字节，所有对话/行为监督由原模型自己 on-policy 生成，8×H200 跑 178.6 小时。
  • 数字（作者自测）：MATH-500、HumanEval+、MMLU-Pro、非思考 GSM8K 与原模型的差距落在配对 bootstrap 区间内；C-Eval、思考 GSM8K、非思考 IFEval 掉 4–6 分；非思考模式字符级任务全面领先（CUTE 75.2→84.0、EXECUTE-zho 81.6→93.9、中文字符套件 54.4→64.0）。代价是吞吐：每步产出少 3–5×，中文字符/秒约为原来的 1/4，64K 字节 prefill 慢 6.5×。论文还记了四种失败模式，其中一条就是 sampling breaking UTF-8。
  • 改变了哪个旧假设：「字节级模型必须靠 patching / 局部 encoder 把字节压成块，或者干脆从头训，且必然大幅掉能力」。它证明训好的 subword 模型可以直接字节化，只动嵌入层和输出头，主能力基本留住。
  • 意义：字符串最原始的表示就是字节数组，字符级操作（数笔画、换字符）不必再靠长链思考硬推；但省下的抽象要用吞吐和显存换。
  • 关联今天：C 里字符串就是 char 数组加一个 '\0'，你今天写的 freq 用 unsigned char 做 256 个桶的下标，就是「一个字节一个 token」最朴素的实现。论文里 sampling breaking UTF-8 踩的坑，跟你按字节反转一个中文字符串会拆碎多字节序列是同一件事——reverse 只保证字节序颠倒，不保证字符还完整。
  • 状态：arXiv 预印本，未经同行评审、待复现；全部数字为作者自测，成本按 8×H200 178.6h 计，暂无独立复现。

2.2 Look Here, Then Decide：小模型 + 确定性流水线大规模挖内存安全漏洞

  • 出处：arXiv:2611.16565《Look Here, Then Decide: Small Decision Models in a Harness Find Memory-Safety Vulnerabilities at Scale on Commodity GPUs》，v1 2026-11-12，cs.CR / cs.LG / cs.SE；作者 Tim De Wachter、Kyryl Volkov、Myrto Eleftheria Gkogkou、Mathieu Huysman；论文首页 Affiliation 印出 Cyrex 与 Deus Rex；https://arxiv.org/abs/2611.16565 。
  • 做了什么：不用前沿大模型，拿 4B 开源决策模型 Intern-Decision-4B 在确定性 harness 里给候选函数打分排序；「往哪看」由 incomplete-fix miners 和 shape localizers 决定，模型只负责把队列排序、不做接受/拒绝裁决。三台 GB10 上扫了 4000+ 个 C/C++ 项目，900–1100 仓库/小时，确认 187 个内存安全发现（按最坏 CVSS v3.1：12 critical、148 high、23 medium、4 low）。决策步单台 GB10 4.4 次/秒、消费级 RTX 4090 9.8 次/秒，分数一致。
  • 数字（作者自测）：模型单用很弱——区分漏洞函数与正常函数 AUC 0.73，区分漏洞函数与它自己的补丁只有 0.56；但用来排序很值：在自家队列里 top10 命中的确认发现是随机顺序的 7.5×（作者标注这是有选择偏差的上界），在 75 个公开 CVE 上修复函数有 21% 进仓库 top25，是随机顺序的 1.4×。作者明确写：召回主要受 localizers 的「看哪」限制，确定性分析与验证仍然不可省。
  • 改变了哪个旧假设：「挖漏洞得靠大模型端到端判断、得堆算力」。它把问题拆成「确定性定位 → 小模型排序 → 确定性验证」，模型只是排序器，消费级显卡就能跑规模化扫描。
  • 意义：把「找越界」从模型能力问题拉回工程流水线问题；同时等于给 C 程序员提了个醒——数组越界、差一错误、下标为负，正是这类扫描的主战场。
  • 关联今天：课表 D5 的检验里明写着「能指出自己代码里一处越界风险」。今天 bounds.c 第 3、5、6 节列的 i<=n、空串 n-1 下溢、signed char 负下标，就是这套流水线在真实项目里找的东西。你今天学会自己指出来，比事后靠工具扫便宜得多。
  • 状态：arXiv 预印本，未经同行评审、待复现；数字为作者自测，187 个发现正按协调披露流程通知维护者，论文发表前不公开细节。

甄别记录：同批还检到 2611.13059（多词 tokenizer，作者自己注明「仅压缩结果、尚未评估训练后的模型」）、2611.11455（编码智能体传播漏洞，属实证分析）、2611.15737（VulSpot 漏洞数据集，属基准建设）。三条要么不是方法突破、要么与今天的「数组/字节」关联偏弱，均未采用；今天两条也未复用 D1–D4 已用的 9 个编号。

今日雷达一句话：字符串的底层就是字节数组，今天你在 C 里手写的下标、反转和 256 桶计数，往大了看是「字节级模型怎么表示文字」，往险了看是「越界怎么变成 CVE」。

3. 新知讲解

3.1 数组：连续内存 + 下标，没有别的

  1. int a[6] 在内存里是 6 个紧挨着的 int，一格 4 字节，总共 24 字节。sizeof(a) 给的是整个数组字节数，sizeof(a)/sizeof(a[0]) 才是元素个数。
  2. 下标从 0 开始不是习惯，是地址运算：a[i] 在 C 标准里的定义就是 *((a)+(i))，a 是首元素地址，+i 走 i * sizeof(int) 字节。所以 &a[i] == a + i，a[i] == *(a+i)。
  3. 加法能交换，所以 i[a] 等价于 *(i+a)，也等于 a[i]。这不是黑魔法，是「下标本质是指针加法」最直接的证据。
  4. 数组不自带长度。编译器只在声明处看得见完整数组，一旦传给函数就退化成指针，sizeof 里外不一样——D9 细讲，今天先记住「长度得自己传」。

3.2 字符串：char 数组 + 结尾一个 '\0'

  1. char s[] = "abcde" 占 6 字节，不是 5：a b c d e \0。strlen(s) 数到 '\0' 前为止返回 5，sizeof(s) 返回 6。
  2. 所有字符串函数都靠这个 '\0' 判断结束，所以缓冲区必须多留一格。反转时 '\0' 原地不动，只换 [0, n-1] 里的字符。
  3. char *p = "abcde" 是字符串字面量，通常落在只读段，改它是未定义行为；要改就用数组 char s[] = "abcde"。D10 画完整内存布局。
  4. 中文是 UTF-8 多字节：一个汉字 3 字节。按字节反转会拆碎编码，输出乱码。今天的 reverse 只处理字节，这是刻意留的边界，不是 bug。

3.3 冒泡排序：把「有序区」从右往左长出来

  1. 双重循环：外层第 i 轮把 [0, n-1-i] 里最大的数推到 n-1-i 位置，内层相邻比较 a[j] > a[j+1] 就交换。
  2. 内层上界是 n-1-i，写成 n 就会访问 a[j+1] 越界——经典差一错误。
  3. 加一个 swapped 标志，某轮没发生交换就提前退出：已排好序的输入只跑 1 轮、4 次比较、0 次交换。复杂度最好 O(n)、最坏 O(n²)、空间 O(1)、稳定（相等不换）。
  4. 5 2 9 1 5 6 0 3 的结果 0 1 2 3 5 5 6 9，7 轮、28 次比较、16 次交换。这个数字要能自己数出来，别只信程序。

3.4 反转：双指针原地换，n<2 先返回

  1. i=0, j=n-1，while (i<j) 交换 s[i] 和 s[j]，两头往中间收。
  2. 必须先 if (n < 2) return：size_t 是无符号，空串 n=0 时 n-1 会绕回成一个巨大数，j 直接飞出缓冲区。这是今天最隐蔽的一处越界风险。
  3. '\0' 不参与交换，strlen 反转前后都是同一个值。

3.5 频次统计：256 个桶，下标必须 unsigned char

  1. 开 long long cnt[256] = {0}，把每个字节的值直接当数组下标，cnt[b]++。这是「值 → 下标」的直接映射，也是后面 D26 哈希表的前置直觉。
  2. 遍历用 const unsigned char *p：char 是否有符号由实现决定，若 char 有符号，0xE4 会变成 -28，cnt[-28] 就是负下标越界。中文、任何 ≥0x80 的字节都会踩。
  3. 输出按字节值 0–255 升序，可打印字符（32–126）连字符一起打，其余打 0xXX，方便核对。
  4. 命令行多个参数会被拼成一个串（中间补一个空格），所以空格也算一个字节、会被统计。

3.6 越界：C 不做边界检查，错了也不报错

  1. 合法下标是 0..n-1。a+n（one-past）算地址合法、解引用非法；a[-1] 直接越界。
  2. for (i=0; i<=n; i++) 会多读一次 a[n]；正确写法是 i<n。
  3. 字符串缓冲区：char buf[5] 装 "abcde" 会挤掉 '\0'；拼接参数必须先算 used + need + 1 > cap 再动手。
  4. 越界是未定义行为，可能读到相邻变量、可能崩、也可能看起来正常——这正是 2.2 那篇论文能在真实项目里扫出 187 个发现的原因。D11 用 AddressSanitizer 把它抓现形。

3.7 最小可运行示例：min.c（无参数，一份文件跑完四件事）

先跑这个把概念对上号，再往下看带参数校验的完整版。

#include <stdio.h>
#include <string.h>

int main(void) {
    int a[6] = {5, 2, 9, 1, 5, 6};
    int n = 6, cmps = 0, swaps = 0;

    /* a[i] == *(a+i) == i[a] */
    for (int i = 0; i < n; i++) {
        printf("a[%d]=%d *(a+%d)=%d i[a]=%d\n", i, a[i], i, *(a + i), i[a]);
    }

    /* bubble sort: inner bound n-1-i, early exit on a clean pass */
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++) {
            cmps++;
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
                swaps++;
                swapped = 1;
            }
        }
        if (!swapped) break;
    }
    printf("sorted:");
    for (int i = 0; i < n; i++) printf(" %d", a[i]);
    printf("\ncompares=%d swaps=%d\n", cmps, swaps);

    /* in-place reverse; guard len>=2 so len-1 cannot underflow */
    char s[] = "Hello, C";
    size_t len = strlen(s);
    if (len >= 2) {
        for (size_t i = 0, j = len - 1; i < j; i++, j--) {
            char t = s[i];
            s[i] = s[j];
            s[j] = t;
        }
    }
    printf("sizeof(s)=%zu strlen(s)=%zu reversed=[%s]\n", sizeof(s), strlen(s), s);

    /* 256 buckets; unsigned char keeps the index in 0..255 */
    int cnt[256] = {0};
    const unsigned char *p = (const unsigned char *)"banana bandana";
    for (; *p != '\0'; p++) cnt[*p]++;
    printf("freq a=%d b=%d n=%d space=%d\n",
           cnt['a'], cnt['b'], cnt['n'], cnt[' ']);

    return 0;
}
gcc -std=c11 -Wall -Wextra min.c -o min.exe && ./min.exe

3.8 完整可运行示例一：array.c（五个模式，编译一次）

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <errno.h>
#include <limits.h>

#define MAX_N 1024
#define MAX_TEXT 4096
#define ALPHA 256

static int parse_ll(const char *s, long long lo, long long hi, long long *out) {
    char *end = NULL;
    errno = 0;
    long long v = strtoll(s, &end, 10);
    if (end == s || *end != '\0' || errno == ERANGE || v < lo || v > hi) return 0;
    *out = v;
    return 1;
}

/* join argv[from..argc-1] with single spaces; bounded by cap */
static int join_argv(int argc, char **argv, int from, char *buf, size_t cap) {
    size_t used = 0;
    buf[0] = '\0';
    for (int i = from; i < argc; i++) {
        size_t len = strlen(argv[i]);
        size_t need = len + (used > 0 ? 1 : 0);
        if (used + need + 1 > cap) return 0;
        if (used > 0) buf[used++] = ' ';
        memcpy(buf + used, argv[i], len);
        used += len;
        buf[used] = '\0';
    }
    return 1;
}

/* O(n^2) bubble sort; early exit on a clean pass */
static void bubble(int *a, int n, long long *cmps, long long *swaps, int *passes) {
    *cmps = 0;
    *swaps = 0;
    *passes = 0;
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        (*passes)++;
        for (int j = 0; j < n - 1 - i; j++) {
            (*cmps)++;
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
                (*swaps)++;
                swapped = 1;
            }
        }
        if (!swapped) break;
    }
}

/* in-place byte reverse; the trailing '\0' stays where it is */
static void reverse_in_place(char *s) {
    size_t n = strlen(s);
    if (n < 2) return;
    size_t i = 0, j = n - 1;
    while (i < j) {
        char t = s[i];
        s[i] = s[j];
        s[j] = t;
        i++;
        j--;
    }
}

/* count each byte value; unsigned char keeps the index in 0..255 */
static void freq(const char *s, long long *cnt, long long *total) {
    *total = 0;
    for (int i = 0; i < ALPHA; i++) cnt[i] = 0;
    const unsigned char *p = (const unsigned char *)s;
    for (; *p != '\0'; p++) {
        cnt[*p]++;
        (*total)++;
    }
}

static void print_int_array(const int *a, int n) {
    for (int i = 0; i < n; i++) printf("%s%d", i ? " " : "", a[i]);
    printf("\n");
}

int main(int argc, char **argv) {
    if (argc < 2) {
        printf("usage:\n"
               "  %s bubble <n> <n ints>\n"
               "  %s reverse <text...>\n"
               "  %s freq <text...>\n"
               "  %s equiv <n> <n ints>\n"
               "  %s addr <n> <n ints>\n",
               argv[0], argv[0], argv[0], argv[0], argv[0]);
        return 2;
    }

    if (strcmp(argv[1], "bubble") == 0 || strcmp(argv[1], "equiv") == 0
        || strcmp(argv[1], "addr") == 0) {
        long long nll;
        if (argc < 3 || !parse_ll(argv[2], 0, MAX_N, &nll)) {
            printf("need n in 0..%d\n", MAX_N);
            return 2;
        }
        int n = (int)nll;
        if (argc - 3 != n) {
            printf("expected %d integers, got %d\n", n, argc - 3);
            return 2;
        }
        int *a = (int *)malloc(sizeof(int) * (size_t)(n > 0 ? n : 1));
        if (!a) {
            printf("out of memory\n");
            return 1;
        }
        for (int i = 0; i < n; i++) {
            long long v;
            if (!parse_ll(argv[3 + i], INT_MIN, INT_MAX, &v)) {
                printf("arg %d is not an int\n", i + 1);
                free(a);
                return 2;
            }
            a[i] = (int)v;
        }

        if (strcmp(argv[1], "bubble") == 0) {
            printf("in   : ");
            print_int_array(a, n);
            long long cmps, swaps;
            int passes;
            bubble(a, n, &cmps, &swaps, &passes);
            printf("out  : ");
            print_int_array(a, n);
            printf("passes=%d compares=%lld swaps=%lld\n", passes, cmps, swaps);
            int sorted = 1;
            for (int i = 0; i + 1 < n; i++) {
                if (a[i] > a[i + 1]) sorted = 0;
            }
            printf("sorted=%s\n", sorted ? "yes" : "no");
        } else if (strcmp(argv[1], "equiv") == 0) {
            printf("i    a[i]   *(a+i)  equal  &a[i]==a+i\n");
            for (int i = 0; i < n; i++) {
                printf("%-4d %-6d %-7d %-6s %s\n", i, a[i], *(a + i),
                       a[i] == *(a + i) ? "yes" : "no",
                       &a[i] == a + i ? "yes" : "no");
            }
            printf("a[0]=%d  0[a]=%d  (C defines E1[E2] as *((E1)+(E2)))\n",
                   n ? a[0] : 0, n ? 0[a] : 0);
        } else {
            printf("base=%p  sizeof(int)=%zu\n", (void *)a, sizeof(int));
            for (int i = 0; i < n; i++) {
                printf("&a[%d]=%p  a+%d=%p  byte_offset=%ld\n", i,
                       (void *)&a[i], i, (void *)(a + i),
                       (long)((char *)&a[i] - (char *)a));
            }
        }
        free(a);
        return 0;
    }

    if (strcmp(argv[1], "reverse") == 0 || strcmp(argv[1], "freq") == 0) {
        char buf[MAX_TEXT];
        if (!join_argv(argc, argv, 2, buf, sizeof buf)) {
            printf("text too long (max %d bytes)\n", MAX_TEXT);
            return 2;
        }
        if (strcmp(argv[1], "reverse") == 0) {
            printf("in   = [%s] (len=%zu)\n", buf, strlen(buf));
            reverse_in_place(buf);
            printf("out  = [%s] (len=%zu)\n", buf, strlen(buf));
        } else {
            long long cnt[ALPHA];
            long long total;
            freq(buf, cnt, &total);
            printf("text   = [%s]\n", buf);
            int kinds = 0;
            for (int i = 0; i < ALPHA; i++) {
                if (cnt[i] > 0) kinds++;
            }
            printf("bytes  = %lld, distinct = %d\n", total, kinds);
            for (int i = 0; i < ALPHA; i++) {
                if (cnt[i] == 0) continue;
                if (i >= 32 && i < 127) {
                    printf("  '%c' (0x%02X / %3d) : %lld\n", (char)i, i, i, cnt[i]);
                } else {
                    printf("  0x%02X (%3d) : %lld\n", i, i, cnt[i]);
                }
            }
        }
        return 0;
    }

    printf("unknown mode: %s\n", argv[1]);
    return 2;
}

parse_ll 用 strtoll + end 指针 + errno == ERANGE 把非法串和超大数挡在数组外面，跟 D3/D4 是同一套。join_argv 里 used + need + 1 > cap 那个 +1 是给 '\0' 留的位，漏了就是缓冲区溢出。

3.9 完整可运行示例二：bounds.c（等价性、地址、越界边界）

#include <stdio.h>
#include <string.h>

#define N 6

int main(void) {
    int a[N] = {10, 20, 30, 40, 50, 60};

    printf("== 1. a[i] is exactly *(a+i) ==\n");
    for (int i = 0; i < N; i++) {
        printf("  i=%d  a[i]=%d  *(a+i)=%d  i[a]=%d  (a+i)-a=%ld\n",
               i, a[i], *(a + i), i[a], (long)((a + i) - a));
    }

    printf("== 2. arrays are contiguous ints ==\n");
    printf("  sizeof(a)=%zu  sizeof(a[0])=%zu  count=%zu\n",
           sizeof(a), sizeof(a[0]), sizeof(a) / sizeof(a[0]));
    for (int i = 0; i < N; i++) {
        printf("  &a[%d]=%p  delta=%ld bytes\n", i, (void *)&a[i],
               (long)((char *)&a[i] - (char *)&a[0]));
    }

    printf("== 3. off-by-one: one-past pointer is legal to FORM, not to READ ==\n");
    int *tail = a + N;
    printf("  valid index range: 0..%d\n", N - 1);
    printf("  a+%d = %p (legal address, reading *(a+%d) is undefined behavior)\n",
           N, (void *)tail, N);
    printf("  a[%d] == *(a+%d) touches memory past the array\n", N, N);
    printf("  loop 'for(i=0;i<=n;i++)' hits a[n] once; correct form is i<n\n");

    printf("== 4. string = char array + terminating '\\0' ==\n");
    char s[] = "abcde";
    size_t len = strlen(s);
    printf("  sizeof(s)=%zu  strlen(s)=%zu  s[5]=%d (the NUL byte)\n",
           sizeof(s), len, s[5]);
    printf("  s[0]=%c  *(s+0)=%c  s[4]=%c  *(s+4)=%c\n",
           s[0], *(s + 0), s[4], *(s + 4));

    printf("== 5. reverse boundary: empty string must not compute n-1 ==\n");
    char empty[] = "";
    printf("  strlen(empty)=%zu; n-1 on size_t would wrap to a huge number\n",
           strlen(empty));
    printf("  guard with if (n < 2) return; before j = n - 1\n");

    printf("== 6. signed char as an index is a real out-of-bounds bug ==\n");
    signed char sc = (signed char)0xE4;
    unsigned char uc = (unsigned char)0xE4;
    printf("  (signed char)0xE4 = %d -> cnt[-28] is a negative index\n", sc);
    printf("  (unsigned char)0xE4 = %d -> cnt[228] is valid\n", uc);

    printf("== 7. safe vs unsafe reverse of a 5-byte string ==\n");
    char t[] = "abcde";
    size_t n = strlen(t);
    for (size_t i = 0, j = n - 1; i < j; i++, j--) {
        char tmp = t[i];
        t[i] = t[j];
        t[j] = tmp;
    }
    printf("  reversed = [%s], len still %zu, t[5]=%d\n", t, strlen(t), t[5]);

    return 0;
}

第 6 节 -28 / 228 是补码、且 char 有符号平台上的结果（主流 x86 编译器都这样）；C 标准把 char 的符号性留给实现，所以正确写法永远是显式 unsigned char。第 2、3 节打印的地址是运行时的真实值，每次跑不一样，看的是「相邻差 4 字节」和「one-past 地址合法」这两件事。

本机没有 C 编译器，上面三份代码已过 C11 语法解析；你在自己机器上按第 4 节命令实编译、实运行，输出以实跑为准。

4.3 课表硬条件二：找出自己代码里的一处越界风险

在 note.md 里至少写 3 条，每条给「错在哪 / 怎么改」：

  1. reverse_in_place 若不写 if (n < 2) return;，空串时 size_t 的 n-1 会绕回巨大值，j 飞出缓冲区。
  2. freq 若用 char * 而不是 unsigned char *，0xE4 变成 -28，cnt[-28] 是负下标越界。
  3. bubble 内层若写 j < n 而不是 j < n-1-i，a[j+1] 会读到 a[n]。
  4. join_argv 若漏掉 +1，拼接结果刚好占满缓冲区时 '\0' 没地方放。
